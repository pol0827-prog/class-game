# ⏱️ 수업이 재밌어지는 5분 — 교실 게임 모음 (교사 화면 + 학생 휴대폰)

수업 도입·마무리 5~10분용 게임 25개. **휴대폰 없이도** 모든 게임이 되고, 휴대폰이 있으면 QR로 들어와 **버튼만 눌러** 참여해요(글자 입력 없음).

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `app.js` | 교사 화면 (게임 21개, 타이머, 점수판, 이름 뽑기, 문제 편집, AI 만들기, 방 만들기) |
| `student.js` | 학생 휴대폰 화면 (방 번호 키패드 → 모둠·이름 탭 → 투표/버저) |
| `data.js` | 게임 목록·진행 방법·기본 문제 ← **문제를 영구적으로 바꾸려면 여기** |
| `cloud.js` | 파이어베이스 저장·로그인·실시간 연결 |
| `config.js` | **배포할 때 고칠 파일** (파이어베이스 설정) |
| `api/generate.js` | 버셀 서버 함수 — Gemini로 문제 생성 (API 키는 서버에만) |
| `firestore.rules` | 파이어베이스 보안 규칙 |
| `vendor/qrcode.js` | QR 코드 생성 (MIT 라이선스) |

## 배포 순서 (약 20분)

### 1. 깃허브에 올리기
1. github.com → **New repository** → 이름 예: `class-opener` → Create
2. **uploading an existing file** → 이 폴더 안의 파일·폴더를 **전부** 끌어다 놓기 (`api`, `vendor` 폴더 포함) → Commit

### 2. 구글 AI 스튜디오에서 API 키 받기
1. aistudio.google.com → **Get API key** → **Create API key** → 복사

### 3. 버셀에 배포
1. vercel.com → **Add New… → Project** → 방금 만든 깃허브 저장소 **Import**
2. Framework Preset: **Other** (그대로) → **Environment Variables** 펼치기
   - `GEMINI_API_KEY` = 2번에서 복사한 키
   - (선택) `GEMINI_MODEL` = `gemini-2.5-flash` (다른 모델을 쓰고 싶을 때만)
3. **Deploy** → 주소 확인 (예: `https://class-opener.vercel.app`)
   - 이 상태에서도 게임·AI 문제 만들기는 바로 됩니다. 학생 휴대폰 연결은 4번까지 해야 돼요.

### 4. 파이어베이스 연결 (학생 휴대폰 참여 + 구글 로그인 저장)
1. console.firebase.google.com → **프로젝트 추가** (애널리틱스는 꺼도 됨)
2. **빌드 → Authentication → 시작하기 → 로그인 방법**
   - **Google** 사용 설정 (선생님 로그인용)
   - **익명** 사용 설정 (학생 참여용 — 학생은 계정 없이 들어와요)
   - **설정 → 승인된 도메인**에 버셀 주소(`class-opener.vercel.app`) 추가
3. **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → 프로덕션 모드
   - **규칙** 탭에 `firestore.rules` 내용을 그대로 붙여 넣고 **게시**
4. **프로젝트 설정(⚙️) → 내 앱 → 웹(</>)** → 앱 등록 → 나오는 `firebaseConfig` 값을 복사
5. 깃허브에서 `config.js` 열기 → ✏️ 편집 → `firebase: null,` 을 아래처럼 바꾸고 Commit
   ```js
   firebase: {
     apiKey: "AIza...",
     authDomain: "....firebaseapp.com",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   },
   ```
   (선택) `publicUrl: 'https://class-opener.vercel.app'` 도 넣어 두면 QR 주소가 항상 이 주소로 나와요.
6. 커밋하면 버셀이 자동으로 다시 배포해요. 오른쪽 위가 `🧪 체험 모드` → `G 구글 로그인`으로 바뀌면 성공!

> 파이어베이스의 apiKey는 공개돼도 되는 값이에요(보안은 규칙이 담당). **Gemini 키는 절대 config.js에 넣지 마세요** — 버셀 환경변수에만.

## 수업에서 쓰는 법

0. 오른쪽 위 **구글 로그인**을 먼저 하세요 (방을 만든 뒤 로그인하면 그 방은 다시 만들어야 해요).
1. 오늘 수업 주제를 입력해 두면 AI 문제 만들기·출구 티켓 등에 자동으로 들어가요.
2. **📱 학생 참여 → 방 만들기** → QR을 TV에 띄우기 → 학생은 카메라로 찍고 **모둠 → 이름**을 눌러 입장
   - 이름 목록은 **👤 이름 뽑기 → ＋ 새 반**에서 미리 만들어 두면 돼요. 없으면 모둠만 골라 익명 참여.
3. 게임 카드를 누르면 학생 휴대폰 화면이 자동으로 그 게임에 맞게 바뀌어요.

| 휴대폰으로 | 게임 | 휴대폰 없이 |
|---|---|---|
| 🗳️ 투표 → 실시간 그래프 | 밸런스 게임, 예측 투표, 마음 날씨, 두 진실 한 거짓, OX 서바이벌, 이해도 신호등 | 손든 학생 수를 `✋+1`로 세기 |
| 🔔 빨리 누르기 버저 → 누른 순서 | 이모지 퀴즈, 초성 퀴즈, 미스터리 키워드, 사진 조각 열기, 한 소절 제목 맞히기 | 먼저 손든 모둠 버튼 눌러 점수 |
| 교사 화면 진행 | 마피아(밤·낮 화면), 끝말잇기·한 단어 릴레이(턴 타이머), 가위바위보 응원단, 칭찬 빗발(돌리기 신호), 폭탄 돌리기(랜덤 폭발), 30초 선생님(A→B 자동 전환), 3-2-1 출구 티켓, 질문 공, 페르미 추정 | — |

- **✏️ 내용 편집**: 한 줄 = 한 문제, `|`로 칸 나누기. **내 문제 세트**로 저장하면 구글 로그인 시 계정에, 아니면 이 브라우저에 저장.
- **✨ AI로 만들기**: 주제·학년·개수·난이도 → Gemini가 만든 결과를 편집 화면에서 확인 후 **적용**.
- 점수판은 학생 휴대폰 위쪽에도 실시간으로 보여요.

## 개인정보 메모
- 명렬(학생 이름)은 선생님 구글 계정 아래(`teachers/{uid}`)에만 저장되고 본인만 읽을 수 있어요.
- 방을 만들 때 "명렬에서 이름 고르기"를 켜면, 그 수업 방에 들어온 학생들이 이름 목록을 볼 수 있어요. 원하지 않으면 끄고 모둠만 고르게 하세요.
- 이해도 신호등 등 응답자 이름은 교사 화면 `응답자 보기`에서만 보여요 (TV에 띄운 상태라면 주의).

## 로컬에서 미리 보기
```bash
python3 -m http.server 8000   # http://localhost:8000
```
파이어베이스 없이 열면 **체험 모드**: 같은 브라우저의 다른 탭에서 `?room=방번호`로 학생 화면을 시험할 수 있어요. (AI 만들기는 버셀에 올린 뒤에 동작)


## 새로 넣은 기능

| 게임 | 내용 |
|---|---|
| 🎮 라이어 게임 | 제시어가 휴대폰으로 몰래 배달됨, 🤡 바보 라이어 모드, 휴대폰 없이 하는 진행법 |
| 🎮 배틀로얄 퀴즈 | 모둠 HP 100, 정답 → 공격/회복/방어막, 5문제마다 자기장 -10, 최후의 1팀 |
| 🎮 가챠 퀴즈 | 정답 → 고전 인물 카드 뽑기(N·R·SR·SSR), 모둠 도감 |
| 🎮 꼬들 | 한글 자모 워들. 🟩🟨⬜ 6번 안에 개념어 맞히기 |
| 🕶️ 교실 마피아 | 경찰·의사·기자·정치인·조커 + 매일 사건 카드. 휴대폰 모드는 직업 배달·밤 행동·투표 자동 처리 |
| 이모지 퀴즈 | 속담·사자성어 / 노래 제목(가사 → 이모지) / 우리 반 친구(이름 + 특징 → 이모지) |
| 초성 퀴즈 · 미스터리 키워드 | "개념 \| 특징" 적으면 초성 문제·힌트 5개 자동 생성 |
| 이해도 신호등 | 선생님이 발문을 넣고 발문별로 🟢🟡🔴 받기 |
| 3-2-1 출구 티켓 | QR로 휴대폰 제출 → 교사 화면에 쌓임, 궁금한 것만 보기, 전체 복사 |

> 마피아 직업·라이어 제시어는 `rooms/{방}/secret/{학생}` 에 저장되어 본인과 선생님만 읽을 수 있어요. **firestore.rules 를 새 버전으로 다시 게시하세요.**
> AI 없이도 초성·키워드 힌트·이모지는 기본 방식으로 만들어지고, 버셀 + Gemini 연결 후에는 더 자연스럽게 만들어져요.
